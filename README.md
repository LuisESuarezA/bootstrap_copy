## GitHub Branching, Merging and Web Page Publishing Practice
This is a practice exercise for using GitHub, branching, merging, and publishing a web page. The web page modelled in the index.html is a simplified version of the ITAM online store <https://tienda.itam.mx/>.

## Steps for github set up

```git branch lesa```

```git checkout lesa```

```git add index.html```

```git add imagenes/portada.png```

```git add imagenes/totebag.png```

```git add imagenes/cup.png```

```git add README.md```

```git commit -m "Initial commit on branch lesa"```

```git push origin lesa```
